# Shipped manifests

Pinned corpora for the Craft apps. Every file is sha256-pinned to a commit of its upstream repo and
fetched over HTTPS from raw.githubusercontent.com. The files themselves are never committed.

Generated by `../scripts/build_manifest.py` (`python3 -I`): it lists the pinned tree through the git
trees API, selects by extension, downloads each file into a temp dir, hashes it, derives tags and
writes the manifest. To move a pin, edit `sha` there and re-run. Exclusions are listed in a comment
at the top of each manifest.

```text
craft-corpus fetch manifests/office-poi.toml corpus/office-poi
craft-corpus verify corpus/office-poi --manifest manifests/office-poi.toml
```

## Exclusions

- Names containing `crash`, `fuzz`, `clusterfuzz`, `cve` or the word `poc` (malicious or fuzz-crash inputs): POI 93, LibreOffice 88, Open XML SDK 1.
- Files over 20 MB: none.
- Empty files (raw.githubusercontent.com answers 501): LibreOffice 2.
- Paths with characters that are not URL-safe (spaces, `%`, `&`, `=`, `~`, non-ASCII), because the fetcher does not percent-encode: POI 7, Open XML SDK 265.
- LibreOffice is limited to `qa` directories of the modules listed above; the repo tree is too large for one recursive API call, so each module subtree is listed separately.

## Tags

Every file has its extension tag. Heuristics: path/name words, plus a look inside the zip (OOXML) or
the DXF text. Heuristics are cheap and can over- or under-tag; treat tags as coverage hints.

- Office, from package contents: `comments` (word/comments, xl/comments, ppt/comments), `tracked-changes` (`w:ins`/`w:del`), `charts`, `pivots` (xl/pivotTables), `tables`, `rtl` (`w:bidi`/`w:rtl`, `rightToLeft`, `rtl="1"`), `fields` (`w:fldChar`/`fldSimple`/`instrText`), `math` (`m:oMath`), `macros` (vbaProject.bin, macro-enabled extension, or a VBA stream in legacy files), `embedded-objects`, `images`, `smartart`, `footnotes`, `formulas`, `conditional-formatting`, `data-validation`, `drawings`, `notes`, `animations`, `transitions`.
- Office, other: `ooxml` / `ole2` (container), `non-ole2` (legacy extension, other container), `not-zip` (OOXML extension that is not a zip), `encrypted` (name or package), `large` (over 1 MB).
- DXF: `ascii` / `binary`, version (`ac1009` ... `ac1032`), entities (`lwpolyline`, `mtext`, `insert`, `hatch`, `dimension`, `spline`, `3dsolid`, `viewport`, ...), `blocks`, `layouts`, `large`, `malformed`.
